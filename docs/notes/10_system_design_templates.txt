StudySync Academic Notes: System Design Architecture Blueprint
=============================================================================
Subject: CS-450 Large Scale Systems Design
Date: 2026-09-16

1. Design Checklist:
   - Functional vs Non-Functional Requirements.
   - Capacity Estimation (RPS, QPS, bandwidth, storage growth over 5 years).
   - High-Level Architecture (CDN, API Gateway, Load Balancers, Microservices, DB Shards).

2. Caching Strategies:
   - Cache-Aside (Lazy loading).
   - Write-Through vs Write-Back.
   - Cache Eviction: LRU, LFU, TTL.

3. Message Brokers & Asynchronous Queues:
   - Event-driven architecture with Kafka / RabbitMQ.
   - Decoupled workers, idempotency keys, dead-letter queues (DLQ).
