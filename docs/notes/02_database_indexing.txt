StudySync Academic Notes: Database Indexing & B-Tree Structures
=============================================================================
Subject: CS-204 Database Management Systems
Date: 2026-09-16

1. B+ Trees:
   - All leaf nodes at identical tree depth.
   - Internal nodes store keys for routing; leaf nodes hold actual records / pointers.
   - Linked leaf nodes allow efficient sequential and range queries (BETWEEN, >=, <=).

2. Hash Indexes:
   - O(1) point lookup complexity.
   - Does not support range scanning.

3. Composite Indexes & Prefix Matching:
   - (colA, colB, colC) covers queries filtering on (colA), (colA, colB), and (colA, colB, colC).
   - Leftmost prefix rule applies.
