StudySync Academic Notes: Graph Algorithms & Dynamic Programming
=============================================================================
Subject: CS-201 Data Structures and Algorithms
Date: 2026-09-16

1. Shortest Path Algorithms:
   - Dijkstra: Non-negative edge weights, priority queue O((V+E) log V).
   - Bellman-Ford: Handles negative edge weights, detects negative cycles O(V*E).
   - Floyd-Warshall: All-pairs shortest paths O(V^3).

2. Minimum Spanning Tree (MST):
   - Kruskal's Algorithm (Disjoint Set Union / Union-Find).
   - Prim's Algorithm (Greedy priority queue expansion).

3. Topological Sort:
   - Kahn's Algorithm (in-degree tracking).
   - DFS with post-order reversal.
