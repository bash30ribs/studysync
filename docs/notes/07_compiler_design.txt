StudySync Academic Notes: Compiler Pipeline & Syntax Trees
=============================================================================
Subject: CS-405 Compiler Design
Date: 2026-09-16

1. Lexical Analysis (Scanner):
   - Converts stream of source characters into tokens (keywords, identifiers, literals).
   - Regex matching with Deterministic Finite Automata (DFA).

2. Syntax Analysis (Parser):
   - Builds Abstract Syntax Tree (AST) using Context-Free Grammars (CFG).
   - Top-down (LL(k), Recursive Descent) vs Bottom-up (LR, LALR).

3. Semantic Analysis & Type Checking:
   - Symbol table resolution and scope management.
   - Type inference and validation.

4. Intermediate Representation (IR) & Optimization:
   - Static Single Assignment (SSA) form.
   - Dead code elimination, loop unrolling, constant folding.
