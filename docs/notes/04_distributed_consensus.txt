StudySync Academic Notes: Distributed Consensus (Raft vs Paxos)
=============================================================================
Subject: CS-402 Distributed Computing
Date: 2026-09-16

1. Raft Algorithm:
   - Roles: Leader, Follower, Candidate.
   - Leader Election with randomized heartbeat election timeouts.
   - Log Replication: Entries committed once acknowledged by majority quorum.

2. CAP Theorem Trade-offs:
   - Consistency (All nodes see same data at same time)
   - Availability (Every request gets a non-error response)
   - Partition Tolerance (System continues functioning despite network splits)

3. Vector Clocks & Lamport Timestamps:
   - Establishing causal ordering of concurrent distributed events.
